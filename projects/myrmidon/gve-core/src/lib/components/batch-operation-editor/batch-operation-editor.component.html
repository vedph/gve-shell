For all the operations:

  • prefix (ITAG:OTAG) to define input and/or output tags, separated by colon.
  • prepend @ to AT to use character indexes (0-N) rather than IDs.
  • RUN (where applicable) defaults to 1.
  • append features like [NAME OPERATOR VALUE], separated by space, where:
    1. NAME is an arbitrary string. Prefixes: *=global features, !=remove feature (no value). Suffixes: ^=short-lived (like *version^=alpha).
    2. OPERATOR is = (multiple), := (single), == (first-single).
    3. VALUE is a string. If it includes spaces, wrap it in "".
